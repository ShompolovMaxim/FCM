## Общее описание

В данном репозитории размещён код "Программы для моделирования результатов обсуждения проблемных ситуаций на основе нечетких когнитивных карт", реализованной в рамках выполнения Выпускной квалификационной работы в рамках обучения на образовательной программе "Программная инженерия" НИУ ВШЭ.

"Программа для моделирования результатов обсуждения проблемных ситуаций на основе нечетких когнитивных карт" - десктопное приложение, позволяющее строить нечёткие когнитивные карты на основе отдельных или агрегированных экспертных оценок, а также осуществлять симуляцию и прогнозирование результатов обсуждения проблемной ситуации, исходя из заданной модели. Программа должна представлять из себя инструмент, позволяющий моделировать предметную область при помощи нечётких когнитивных карт и производить пошаговый расчёт значений факторов, а также создавать основу для формулирования выводов для проводимой дискуссии по проблемной ситуации.

## Основные функциональные требования

Построение НКК:
- Графический метод
- Табличный метод
- Настройка термов, факторов, связей

Симуляция:
- Применение различных методов прогнозирования
- Графическое представление динамики значений факторов
- Управление симуляцией

Результаты прогнозирования:
- Цветовое отображение на графе
- Графики значений факторов и связей

Другие функции по работе с НКК:
- Анализ чувствительности модели и статический анализ
- Объединение НКК

Прочие функции:
- История экспериментов
- Ручное и автоматическое сохранение моделей и шаблонов
- Экспорт и импорт
- Создание заметок Markdown
- Интерфейс на русском и английском языках

        - prediction – директория с логикой предсказания НКК
        - sensitivity_analysis – директория с логикой анализа чувствительности НКК

## Сборка проекта

- установить Qt 6.10.1 с компилятором MinGW
- установить CMake версии не ниже 3.16
- клонировать репозиторий, указанный в разделе 1, и установить используемые библиотеки при помощи команды `git submodule update --init --recursive`
- установить переменные окружения командой (подставить путь к компилятору Qt): `call C:\Qt\6.10.1\mingw_64\bin\qtenv2.bat`
- перейти в директорию с репозиторием
- настроить проект для сборки командой:  
`cmake -S . -B build-cmd -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release -DCMAKE_C_COMPILER=gcc -DCMAKE_CXX_COMPILER=g++`
            
- выполнить сборку командой `cmake --build build-cmd --parallel`
- выполнить добавление dll файлов командой: `windeployqt --release build-cmd\FCM.exe.`
- в результате готовый к запуску исполняемый файл будет размещён по пути `build-cmd\FCM.exe`.

## Скачивание и запуск приложения
Приложение может быть скачано (установлено) двумя способами:
- в форме арихива
- в форме установщика.

Каждый из этих файлов прикреплён к последнему релизу по ссылке https://github.com/ShompolovMaxim/FCM/releases

- при скачивании архива необходимо выполнить распаковку и запустить файл `FCM.exe` в корневой директории.
- при использовании установщика необходимо пройти визард, который позволит создать ярлык на работем столе.
